# zaycev-download.user.js
Tampermonkey script to download from zaycev.net

## Возможности

- Добавляет кнопки скачивания треков без штатной кнопки, включая подгружаемые через «Показать ещё».
- Позволяет скачать текущий трек из нижнего плеера.
- Скачивает все доступные треки исполнителя со всех страниц.
- Поддерживает 1–3 параллельные загрузки с паузой 5 секунд между партиями.
- Позволяет остановить очередь с подтверждением и продолжить без повторов в текущей вкладке.
- Показывает прогресс на странице и в заголовке вкладки: `🎵 10/87`.
- Предупреждает о закрытии или обновлении вкладки во время загрузки.
- Записывает название, исполнителя и обложку в теги MP3. Использует оригинальную обложку, при её отсутствии - большую версию сайта.
- Сохраняет аудио без перекодирования, а имена файлов — без ID трека.
- Останавливает очередь при HTTP 401, 403 или 429 без автоматических повторов.
