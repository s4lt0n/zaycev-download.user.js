## Zaycev.net Downloader для Tampermonkey

- Скачивание доступных для прослушивания треков из списка и плеера — единые кнопки без дублирования.
- Название, исполнитель и оригинальная обложка в тегах MP3.
- Загрузка всех треков исполнителя: 1–5 параллельно, паузы между пачками, остановка и продолжение.
- Прогресс-бар, счётчик в заголовке вкладки и анимированные названия треков.
- Подтверждение остановки и предупреждение при закрытии вкладки.
- Автоматическая остановка при HTTP 401, 403 или 429.

**Установка:** вставьте код `.user.js` в новый скрипт Tampermonkey, сохраните и обновите страницу.

Обходит отсутствие кнопки скачивания, но не серверные ограничения доступа.
